\begin{abstract}
    算力与高质量语料的双重约束，使大语言模型的性能提升不再只是参数量和训练 Token 数的扩张问题。数据的质量与领域组成影响单位 Token 的训练价值，而质量治理和长上下文计算又会占用有限预算。本文围绕语料评价、广义资源--损失关系及联合配置建立递进模型，以验证损失衡量前三问的性能响应，并区分真实观测、半合成校准与外推情景的证据边界。

    \textbf{针对问题一：}对七个语料领域的 22 项异质质量信号进行优劣方向审计、域均衡标度和九个信息簇的层次聚合，形成样本与领域质量分；再以域内条件残差识别异常冲突，并对相应证据作可靠性重加权。同源扩展语料与对应抽样领域的质量均值接近；质量评分与 210 条人工复核结果的 Spearman 相关为 $0.666$。冲突修正前后的全样本排序相关为 $0.9992$，而高冲突的前 $10\%$ 样本贡献了 $64.8\%$ 的总绝对修正量，表明校正主要作用于异常尾部。针对 17 域训练配比，在单纯形约束下分别以 ILR--Ridge 预测损失、以多任务稀疏 Scheff\'e 模型解释来源替换与交互；前者在真实检验集的 13 个评估目标上取得平均 $R^2=0.765$。配比排序相关在 60M 和 1B 规模分别为 $0.810$ 与 $0.608$，据此界定配比规律的规模迁移边界。

    \textbf{针对问题二：}以真实训练轨迹锚定经典标度律，对异源损失实施仿射尺度归一化，并以可分离非线性最小二乘和自适应结构早停辨识规模参数。跨模型族观测的归一化 $R^2$ 为 $0.9240$，说明规模规律在校准损失口径后具有一定迁移性。在经典基线上，以质量加权来源份额和中心化对数比特征刻画配比响应，采用锚定基线、分阶段辨识及因子对照的方式建立广义标度律；13 个评估目标在三个已观测规模上的留出预测相对 RMSE 汇总为 $5.54\%$，中心化配比效应的 $R^2$ 为 $0.9006$。单独变化质量的校准数据主拟合 $R^2$ 为 $0.9568$，在 $Q=0.6$ 处的损失弹性约为 $-0.0482$。固定参考配比、$N=10^9$ 及 $D=250$ 亿 Token 时，质量由 $0.6$ 提升至 $0.7$ 的等损失 Token 节省量为 $13.97$ 亿；叠加可行的一个百分点配比调整后，中位数为 $14.06$ 亿。上述数值是质量--配比耦合假设下的模型情景推算，其适用边界由观测规模、质量标定范围及配比支撑域共同限定，超大规模质量响应与实际训练收益尚不在验证范围内。

    \textbf{针对问题三：}以前两问交接的逐目标损失响应构造优化目标，将配比限制在 512 组真实训练配方的凸包内，联合配置参数量、Token 数、领域份额与治理质量；成本同时计入基础训练、增量质量治理和外生上下文长度对应的注意力开销。在 11 档预算、5 档上下文及 3 种质量成本函数形成的 165 个联合配置情景中，相对同预算规模基线的平均损失改善为 $4.16\%$--$5.81\%$。其中 162 个情景至少有一个评估目标的损失上升，明确了平均改善的逐领域收益边界；有限候选在已设定质量收益情景中的最大相对后悔值为 $1.5465\%$。注意力成本与基础训练成本相当的临界上下文长度为 $30000$，超过该长度后序列开销显著挤占规模预算。固定配比的局部情景出现质量治理启动，但联合配置未达到跨情景稳定的结构转移判据。配置数值限定于已辨识响应函数和既定成本口径，实际应用仍需重新校准治理成本及逐领域损失。

    \keywords{数据质量评价；领域配比；广义标度律；质量--规模替代；算力约束优化}
\end{abstract}

\section{问题重述}
\subsection{问题背景}

大语言模型正逐渐成为知识获取、内容生成与复杂任务处理的基础技术。其能力提升长期依赖更大的参数规模和更充分的训练，但参数、数据与算力的扩张需要同步投入：模型越大，单次训练所需的计算和存储资源越多；训练越久，新增 Token 带来的收益也逐步减弱。规模投入仍然重要，却难以单独回答有限资源应投向何处的问题。

训练语料并非同质的 Token 集合。不同来源在事实密度、语言表达、专业知识、代码与数学内容以及重复和噪声程度上存在差异；数量相同的语料，对模型能力的贡献可能并不相同。高质量语料的获取、清洗和组织需要额外投入，某些专业领域的有效内容又难以无限扩充。与此同时，训练数据由多个领域共同组成，一个领域份额的增加必然挤占其他领域，因而语料配比体现的是不同知识覆盖之间的取舍，而不是可以独立增加的资源总量。

有限算力进一步耦合了这些选择。扩大模型、增加训练 Token、提升语料质量与支持更长上下文都会消耗预算；长序列带来的注意力开销尤其会改变既定预算中可用于参数和数据的比例。不同投入的收益和成本随资源水平而变化，低预算下的有效策略未必适用于更高预算。另一方面，架构、训练方法和数据工程的进步也会改变资源转化为模型能力的效率，使能力增长不能完全归因于规模扩张。如何协调模型规模、语料数量与价值、领域结构及上下文需求，因而成为算力约束下大语言模型发展的核心资源配置问题。

\subsection{问题重述}
本文围绕“有限算力如何转化为更高模型能力”这一核心问题，依次研究数据价值、训练损失、资源配置和能力前沿。四项任务既相互衔接，又对应不同的观测量和验证方式：
\begin{enumerate}
    \item \textbf{数据质量评价与领域配比建模。}多维质量信号的量纲、优劣方向和领域覆盖各不相同，首先需要将其转化为方向一致、可跨领域比较的质量评分，并明确由样本到语料及训练来源的聚合规则。当同一文本的质量指标相互矛盾时，还需定义冲突程度、分析证据可靠性并提出消解方法，检验结论在不同数据范围内是否稳定。在此基础上，针对训练来源份额非负且总和为 $1$ 的约束，建立领域配比与验证损失的定量关系，辨别单一来源的替换效应和来源组合的互补或竞争作用。
    \item \textbf{广义标度律与替代条件。}不同训练轨迹及模型体系的原始损失未必处于统一尺度，需要先建立可比口径，辨识经典标度律并检验其跨轨迹、跨模型族的泛化能力。随后将整体数据质量 $Q$ 和领域配比 $\mathbf p$ 纳入 $N$、$D$ 与 $L$ 的关系，提出可估计、可验证的广义标度律；其中质量效应与配比效应必须区分，不能从固定来源质量的配比变化中直接推断独立的质量收益。进一步计算各因素的边际降损与弹性，在给定工作点和目标损失下，推导语料质量、配比与规模投入可相互替代的条件及其外推边界。
    \item \textbf{算力预算下的资源联合优化。}在训练开销、质量提升开销和长上下文开销共同约束下，求解参数量、训练 Token 数、整体质量与领域配比的联合配置。上下文长度由架构与任务需求外生给定，而非与其他因素一同自由寻优；需分析其可行取值对剩余预算的挤占。比较不同质量成本形式及多个量级的算力预算，给出最优配置和性能变化，并用可检验的判据识别预算增加时资源分配是否出现结构性转移。
    \item \textbf{技术演进分解与能力前沿预测。}利用历史模型的发布日期、规模与多维评测记录，界定综合能力指标以及开源模型、预训练模型和对话微调模型的比较口径，分离规模扩张与非规模技术进步对能力增长的贡献。由于前三项任务以验证损失为主要结果变量，而能力前沿以评测得分衡量，还需建立两者之间的桥接关系并分析映射误差。在算力增长放缓的情景下预测未来开源模型的能力边界，同时给出时间跨度、任务差异和数据不确定性对预测的影响。
\end{enumerate}

\section{数据说明与预处理}

\subsection{数据来源及可信度分层}

本文按证据功能而非文件顺序组织数据。语料质量评价以多维质量信号抽样及扩展记录（A1--A3）为基础；领域配比与验证损失由成对的训练表（A4、A5）建立关联，并以同尺度及跨尺度检验表（A6--A11）评估泛化。更大规模的配比与损失表（A12--A15）属于子集配方和外推估计，仅用于考察趋势的稳健性；跨领域质量映射采用参考对应关系（A16），其不确定性在解释时保留。

规模基线锚定于真实训练日志（B1），再以半合成的族外日志（B2）、插值轨迹（B3）、跨模型族观测（B4）及文献数据（B5）进行分层检验。独立质量变化由校准生成的质量实验（B6、B7）提供；含大规模推算的扩展表（B8）不作为直接观测验证。超大模型的参数资料与预估损失（B9、B10）也分别承担情景设定和外推对照的角色，不能混作同等级证据。能力演进分析可依托多维排行榜及其替代版本（C1、C2）、时序记录（C3）、模型元数据（C4）、损失--评测桥接样本（C5、C6）和逐任务结果（C8）；上下文长度的可行范围则参考架构元数据（C7）。上述来源在建模中分别用于估计、验证或情景分析，半合成、插值与估算结果均不等同于独立实测。

\subsection{数据口径统一}

质量信号先按指标含义统一为“越高越好”，再将各领域经验分布等权合成为公共标尺；由抽样语料确定的标量化和变换规则在同源扩展语料中保持不变。样本质量经领域聚合后，通过参考映射构成训练来源的质量描述 $\mathbf Q^{(17)}$。这一向量与后文表示整体治理等级的标量 $Q$ 含义不同：在配比记录中各来源 $Q_i^{(17)}$ 固定，$p_iQ_i^{(17)}$ 不能提供独立改变质量的信息。

配方表与损失表按共同标识逐行对应；17 个训练来源份额满足单纯形约束，13 个评估目标的损失保留各自口径。问题一的总体配比指标在训练样本内逐目标进行中位数--MAD 标准化。问题二以主训练日志的交叉熵损失为参考尺度，对其他模型来源只校准其仿射位置与幅度，不直接合并原始损失。参数量与 Token 数在计算成本中统一换算为绝对个数，以免十亿单位与 FLOPs 混用。

\subsection{训练、检验及外推数据划分}

配比响应由训练配方及对应损失估计，同尺度和跨尺度的真实检验表用于评价迁移；更大规模的估算损失仅用于情景外推。同源扩展质量语料用于检查抽样评价的代表性，不作为独立重复实验。经典标度律的参数由主训练日志估计，其他来源参与结构选择与分层比较，但不回流重估主律参数；因此结构选择所用数据与完全未接触的外部测试须加以区分。

广义律按配方划分拟合与留出样本：逐行配对的规模使用相同配方划分，另一观测规模独立划分，避免同一配方在训练与检验间泄漏。两组质量实验存在精确的样本包含关系，只能提供子集一致性对照；含大规模推算的质量表与预估损失不计作直接观测。问题三以此前辨识的损失响应进行条件优化，其预算情景结果也不等同于新增的模型训练实验。

\section{问题一：数据质量评价、冲突消解及领域配比}
\label{sec:q1}

附件 A 包含两类相互衔接的数据，A1--A3 给出语料的多维质量信号，A4--A15 给出不同领域配方及其验证损失。
本问依次解决三个层次的问题。首先在七域样本不均衡条件下构造初始质量 $Q^{(0)}$；随后依据各领域内部的正常指标关系识别异常评价证据，并校正其权重得到 $Q^*$；最后在单纯形约束下建立 17 域训练配比对 13 域验证 Loss 的联合响应。
$Q^*$ 经 A16 映射为来源质量向量 $\mathbf Q^{(17)}$，并与总体配比效应 $\phi(\mathbf p)$ 一同作为问题二的数据侧输入。

\subsection{数据质量评价}
\label{subsec:q1_quality}

A1 含 51,230 条样本、7 个领域和 22 项质量信号；A2、A3 分别是 arxiv 和 github 的扩展抽样集合，各含 17,523 条和 203,752 条样本，并完整包含 A1 对应领域的 1,419 条与 10,000 条样本。

\subsubsection{域均衡层次质量评价}

A1 中 book 仅 171 条、arxiv 为 1,419 条，而 c4、github、stackexchange、wikipedia 均接近 $10^4$ 条。
若以全样本经验分布作为统一标尺，大样本领域将获得更高权重；若分别在域内归一化，则会抹去域间真实差异。
因此，对指标 $j$ 在领域 $d$ 内建立经验分布 $F_{jd}$，并令七个领域等权参与公共参考尺度，即
\begin{equation}
    F_j^{\mathrm{bal}}(x)=\frac{1}{7}\sum_{d=1}^{7}F_{jd}(x).
    \label{eq:q1_bal_ecdf}
\end{equation}
在此基础上，将不同方向的指标统一为 $s_{ij}\in[0,1]$，具体形式为
\begin{equation}
    s_{ij}=
    \begin{cases}
        F_j^{\mathrm{bal}}(x_{ij}),                           & j\in\mathcal P, \\[2pt]
        1-F_j^{\mathrm{bal}}(x_{ij}),                         & j\in\mathcal N, \\[2pt]
        \min\!\left\{\dfrac{F_j^{\mathrm{bal}}(x_{ij})}{0.20},
        \dfrac{1-F_j^{\mathrm{bal}}(x_{ij})}{0.20},1\right\}, & j\in\mathcal M,
    \end{cases}
    \label{eq:q1_suitability}
\end{equation}
其中 $\mathcal P,\mathcal N,\mathcal M$ 分别表示正向、负向和中心适宜指标集合。中心适宜函数在中间 60\% 分位区间取满分，仅对结构极端样本进行惩罚。

统一表征后，以域均衡权重计算 22 项信号的 Spearman 相关矩阵，并以 $1-|\rho|$ 为距离进行层次聚类。
综合轮廓系数和 120 次分层 bootstrap 的配对稳定度，数据驱动选择 $K=9$ 个信息簇。对第 $k$ 个信息簇 $G_k$，以簇内绝对相关矩阵的最大特征向量形成非负权重 $a_{jk}$；不同簇之间采用等权，即
\begin{equation}
    H_{ik}=\sum_{j\in G_k}a_{jk}s_{ij},\qquad
    Q_i^{(0)}=\frac{1}{K}\sum_{k=1}^{K}H_{ik},\qquad K=9.
    \label{eq:q1_q0}
\end{equation}
这种层次合成先在同类信号中提取共识，再汇总不同质量语义，从而削弱重复评价对综合分数的影响。
图~\ref{fig:q1_quality_structure} 表明，域均衡相关矩阵呈明显的簇状结构，顶部色带给出信息簇归属，右侧给出领域间方差占比 $\eta_j$ 与指标方向。
多个 DSIR 与模型评分信号的 $\eta_j$ 超过 0.60，说明其变化更多来自领域身份而非通用质量，因此这些指标只参与综合评价，不单独解释为领域质量的因果来源。

\subsection{质量冲突消解}
\label{subsec:q1_conflict}

$Q^{(0)}$ 的合成默认各项质量证据均可直接使用，但特殊文本可能使个别评价器偏离该领域的常见关系。
因此，本文把“正常的多维差异”与“异常的不一致”分开处理。只有当某项观测显著偏离同域相关信号所预测的正常水平时，才记为质量冲突；随后降低该项证据在综合评价中的权重。

\subsubsection{质量冲突的域感知识别}

以上一节的域均衡相关结构为基础，仅保留 $|\rho|\ge0.10$ 且在 300 次分层 bootstrap 中稳定率不低于 0.95 的指标关系，共得到 135 条稳定边。
对每项指标，用其稳定邻居和领域信息建立 Elastic Net 预测器，并按七域进行 5 折 cross-fitting，使每个样本的条件期望均由未包含该样本的训练折给出。
记交叉预测残差为 $e_{ij}=s_{ij}-\widehat s_{ij}^{(-i)}$，并在所属领域内按 MAD 标准化。若异常度进入对应“指标--领域”经验残差分布的上 2.5\% 尾部，则置 $I_{ij}=1$。样本级冲突度同时计入异常覆盖范围和异常强度，即
\begin{equation}
    \begin{aligned}
        r_{ij}                 & =\frac{|e_{ij}|}{1.4826\,\mathrm{MAD}_{d_i}(e_{\cdot j})+\varepsilon}, \\
        p_{ij}^{\mathrm{conf}} & =1-F_{j,d_i}^{R}(r_{ij}),\qquad
        I_{ij}=\mathbf{1}\!\left\{p_{ij}^{\mathrm{conf}}<0.025\right\},                                 \\
        C_i                    & =\sqrt{\left(\frac{1}{22}\sum_j I_{ij}\right)
            \left(\frac{\sum_j I_{ij}r_{ij}}{\sum_j I_{ij}+\varepsilon}\right)}.
    \end{aligned}
    \label{eq:q1_conflict}
\end{equation}
该定义以各指标在各领域中的正常波动为参照，因此不会把代码、公式密集文本等领域特征仅因数值差异而判为冲突。

\subsubsection{冲突证据的可靠性重加权}

冲突不直接从样本总分中扣除，而是作用于对应证据的可靠度。设 $\tau_{j,d_i}$ 为指标 $j$ 在领域 $d_i$ 的冲突阈值，定义
\begin{equation}
    R_{ij}=\begin{cases}
        1,                                   & I_{ij}=0, \\
        \exp\{-0.5(r_{ij}-\tau_{j,d_i})_+\}, & I_{ij}=1,
    \end{cases}
    \qquad
    Q_i^*=\sum_{k=1}^{K}v_{ik}^*H_{ik},\quad
    v_{ik}^*=\frac{\sum_{j\in G_k}a_{jk}R_{ij}}
    {\sum_{\ell=1}^{K}\sum_{h\in G_\ell}a_{h\ell}R_{ih}}.
    \label{eq:q1_qstar}
\end{equation}
各信息簇可靠度的均值记为 $U_i$。当不存在冲突时，$v_{ik}^*=1/K$，故 $Q_i^*=Q_i^{(0)}$；出现局部异常时，仅相应信息簇的权重发生变化。

Top 10\%、Top 5\% 和 Top 1\% 冲突样本的 $|Q^*-Q^{(0)}|$ 中位数分别为 0.00435、0.00655 和 0.0118，且 Top 10\% 样本贡献了 64.8\% 的总绝对修正量。图~\ref{fig:q1_conflict_resolution} 中的分箱中位线进一步显示，冲突程度升高后修正幅度呈持续上升趋势。

\subsection{领域配比--Loss关系}
\label{subsec:q1_mixture}

A4/A5 提供 512 组 1M 训练配方及其 13 域验证 Loss；A6/A7 为 1M 同尺度真实检验，A8/A9 和 A10/A11 分别提供 60M、1B 真实检验，A12--A15 为 10B、70B 外推表。
17 个训练比例满足 $p_i\ge0$、$\sum_i p_i=1$，而 13 个验证域的 Loss 基准不同，因此建模时需同时处理单纯形约束、多输出响应和跨尺度迁移。

\subsubsection{配比数据标准化及质量先验检验}

不同验证域的 Loss 先在 A5 内按验证域进行中位数--MAD 标准化，再定义总体配比表现，即
\begin{equation}
    z_{mk}=\frac{L_{mk}-\operatorname{median}(L_{\cdot k})}
    {1.4826\,\operatorname{MAD}(L_{\cdot k})},\qquad
    \phi(\mathbf p)=-\frac{1}{13}\sum_{k=1}^{13}\widehat z_k(\mathbf p).
    \label{eq:q1_phi}
\end{equation}
$\phi(\mathbf p)$ 越大，表示该配方在 13 个验证域上的总体表现越优。

第二小问得到的七域 $Q^*$ 经 A16 映射到 17 个训练域，记为 $\mathbf Q^{(17)}=(Q_1^{(17)},\ldots,Q_{17}^{(17)})$。由于 $\sum_i p_iQ_i^{(17)}$ 是 $\mathbf p$ 的确定函数，直接作为额外线性项会与配比变量共线。
因此以指数倾斜 $\widetilde p_i(\gamma)\propto p_i\exp[\gamma(Q_i^{(17)}-\bar Q)]$ 检验质量先验。交叉验证的最优值为 $\gamma=0$，且 $\gamma>0$ 时误差略有增加，说明 A4/A5 无法把“领域身份”与“领域质量”的独立作用分开识别。
本小问据此不引入质量先验，质量的独立边际效应转由校准生成的质量变化实验（B6、B7）估计；大规模扩展结果（B8）仅用于审视外推边界。

\subsubsection{配比--Loss 响应的预测与解释模型}

为显式刻画领域及领域组合的作用，对第 $k$ 个验证域建立二阶 Scheff\'e 混合响应
\begin{equation}

\subsubsection{领域份额替换及互补结构}

在单纯形约束下，“增加领域 $i$”必然伴随其他领域份额减少，因此主效应系数不能直接解释为独立边际收益。
在参考配比 $\mathbf p$ 附近，定义从领域 $j$ 向领域 $i$ 转移份额的边际效应和两领域的总体互补指数，即
\begin{equation}
    S_{i\leftarrow j}(\mathbf p)=\frac{1}{13}\sum_{k=1}^{13}
    \left(\frac{\partial\widehat z_k}{\partial p_i}-\frac{\partial\widehat z_k}{\partial p_j}\right),\qquad
    C_{ij}^{\mathrm{mix}}=-\frac{1}{13}\sum_{k=1}^{13}\gamma_{ijk}.
    \label{eq:q1_sub_comp}
\end{equation}
$S_{i\leftarrow j}<0$ 表示在当前配比附近将份额从 $j$ 转移到 $i$ 有助于降低总体 Loss；$C_{ij}^{\mathrm{mix}}>0$ 表示两域共同出现时的 Loss 低于线性混合预期。
前者描述份额替换，后者描述非加性交互。

为控制稀疏配方造成的大系数伪影，正文只解释同时满足三项条件的关系，即两域训练覆盖充分、bootstrap 符号稳定率不低于 0.95、效应量位于训练支持范围。
约 52\% 的替换关系和 46\% 的互补关系通过该门槛。通过门槛的关系中，DM-Math $\rightarrow$ HackerNews 的替换效应为 $-2.68$，显示稳定的 Loss 改善信号；arXiv--GitHub 则表现出稳定互补。
相反，\texttt{enron\_emails} 的平均份额仅 0.0022、最大份额 0.026、非零占比 0.31，其大幅替换效应超出充分支持范围，因此不进入机制结论。

\section{问题二：广义标度律及语料规模---质量、配比替代}

\subsection{经典标度律的扩展动因与分析框架}

\subsubsection{经典标度律的局限}

经典标度律通常将训练 Token 视为同质资源，重点描述参数规模和数据规模对模型损失的影响。然而，随着高质量语料逐渐稀缺，不同数据在信息密度、噪声水平、知识覆盖和任务相关性方面呈现出显著差异，单纯增加参数量或训练 Token 数已不足以准确解释模型能力的增长规律。如果忽略这种数据异质性，模型不仅会高估低质量数据的边际价值，还会掩盖领域结构失衡造成的性能瓶颈，从而难以回答数据质量提升、领域配比调整与模型规模扩张之间能否相互替代这一关键问题。因此，将数据质量和领域配比纳入标度律，是从“规模驱动”转向“规模与数据价值协同驱动”的必要拓展，也是实现有限算力下精细化资源配置的理论基础。

这一局限在固定规模的比较中尤为清楚，当模型参数量和训练 Token 数相同时，经典律给出相同的损失基线，却不区分语料来源的替换与质量等级的改变。故规模项可以刻画投入增加的平均趋势，不能单独解释同等训练规模下的损失差异。本文以验证损失为可建模的响应量，讨论的“替代”也首先是达到相同目标损失所需资源的变化，而非将损失改善直接等同于所有下游能力的提升。

\subsubsection{数据结构与可辨识约束}

数据结构决定了这一拓展不能简单地用一个质量系数修正训练 Token 数。设训练数据来自 $m$ 个领域，配比 $\mathbf p$ 满足 $p_i\geq0$ 与 $\sum_{i=1}^{m}p_i=1$，任一来源份额的增加必然挤占其他来源。来源质量 $Q_i$ 由问题一的数据分级给定；在本文的 17 域实例中，$Q_i=Q_i^{(17)}$，并在现有配比实验中保持固定。若把完整配比压缩为平均质量 $\sum_i p_iQ_i$ 或单一有效数据量，质量等级相同但知识内容不同的来源将无法区分，跨评估目标的差异化响应也会被掩盖。同时，固定的 $Q_i$ 与来源身份交织，不能仅凭这些实验识别独立提高质量的效应。可观测的模型---数据规模组合较少，不同体系的原始损失又存在尺度偏移，因此盲目增加交互项或直接混合损失均会削弱参数的可辨识性。

因此，配比变化与质量提升必须采用不同的识别口径。前者是在给定来源质量下沿配比单纯形重新分配份额，其收益取决于被增加和被压缩的来源以及评估目标；后者需要单独变化整体质量等级的实验信息。在仅改变配比的记录中，$p_iQ_i$ 随 $p_i$ 变化并不意味着观测到了 $Q_i$ 的独立变化。将这两种机制区分开，才能避免把“更换训练来源”的效果误写成“提高同一来源质量”的效果。

\subsubsection{分阶段修正的标度律扩展框架}

基于上述约束，本文采用“经典规模基线---组成响应---独立质量校准”的分层建模框架。首先，对多来源损失进行尺度归一化，利用自适应结构早停识别稳健的经典标度指数。随后针对任意评估目标，在规模基线上叠加配比响应项，以质量加权份额 $p_iQ_i$ 表示分级质量与投入的联合暴露，以中心化对数比特征刻画单纯形上的相对组成，并允许响应幅度随 $N$、$D$ 变化。该设计保留了经典标度律对规模收益递减的解释，同时允许相同质量等级的不同来源产生不同的损失变化。受规模锚点数量限制，扩展模型沿用下文辨识的经典指数，而不从配比实验中重新辨识所有规模参数。

整体质量等级 $Q$ 的作用则由单独变化质量的实验标定，并以参考质量 $Q_0$ 与已辨识的规模---配比关系衔接。这样，组成响应与质量响应各有对应的信息来源，也能清楚标识二者联合变化所依赖的结构假设。在此基础上，固定模型规模和目标损失，比较不同 $Q$ 与可行配比 $\mathbf p$ 下所需的训练 Token 数 $D$，才能定义语料规模---质量、配比的等损失替代。该替代是给定工作点及模型适用范围内的条件关系，其边界将在后文单独讨论。

\subsection{损失尺度归一化与锚定分阶段标度律建模}

\subsubsection{经典标度律基线的辨识与适用边界}

为刻画模型规模、训练数据量与验证损失之间的基本数量关系，本文以真实训练日志（B1）辨识经典标度律，并将族外日志、插值轨迹及跨族和文献样本（B2--B5）保留为不同层级的检验证据。所采用的经典形式为
\begin{equation}
    L(N,D)=E+A N^{-\alpha}+B D^{-\beta},
    \label{eq:classic-scaling-law}
\end{equation}
其中，$N$ 表示模型参数量，$D$ 表示训练 Token 数，$L$ 表示验证集交叉熵损失。$E$ 是规模趋于充分时仍无法消除的不可约损失，$A$ 与 $B$ 分别控制参数规模项和数据规模项的幅度，$\alpha$ 与 $\beta$ 则刻画两类资源的边际收益衰减速度。为保证模型具有明确的物理含义，估计过程中施加
\begin{equation}
    0\leq E<\min_i L_i,\qquad
    A>0,\quad B>0,\quad \alpha>0,\quad \beta>0
\end{equation}
等约束。由式~\eqref{eq:classic-scaling-law}可知，随着 $N$ 或 $D$ 增大，预测损失单调下降，但改善幅度逐渐减小，因而能够自然描述大模型训练中的收益递减现象。

\paragraph{损失尺度归一化}

不同模型体系可能采用不同的分词器、验证语料和损失统计口径，即使其学习曲线具有相似形状，原始 Loss 的位置和尺度也可能存在系统差异。若直接比较原始损失，模型族之间的整体平移或缩放会被误判为标度结构失效。为此，本文将主拟合来源的 Loss 定义为参考尺度，并假设第 $j$ 个外部来源的观测损失满足仿射观测关系
\begin{equation}
    L_{ji}^{\mathrm{obs}}
    =a_j+b_j L_{ji}^{\mathrm{ref}}+\varepsilon_{ji},
    \qquad b_j>0,
    \label{eq:loss-affine-map}
\end{equation}
其中，$a_j$ 描述损失基线差异，$b_j$ 描述损失单位或动态范围差异，$\varepsilon_{ji}$ 为无法由统一尺度解释的结构残差。相应地，将外部观测映射到参考尺度：
\begin{equation}
    \widetilde L_{ji}
    =\frac{L_{ji}^{\mathrm{obs}}-a_j}{b_j}.
    \label{eq:loss-normalization}
\end{equation}
主拟合来源取 $a_0=0$、$b_0=1$，因此其训练过程保持在原始可解释的 Loss 尺度上。其他来源经式~\eqref{eq:loss-normalization}归一化后再参与验证与结构选择。

为防止利用同一批验证标签完成校准后又在原样本上评价，本文采用按训练轨迹或模型族分簇的交叉归一化。对于待评价簇 $c$，仅使用其余簇估计
\begin{equation}
    (\widehat a_j^{(-c)},\widehat b_j^{(-c)})
    =\arg\min_{a\in\mathbb R,\,b>0}
    \sum_{i:\,g(i)\neq c}
    \left[L_{ji}^{\mathrm{obs}}-
        \left(a+b\widehat L_{ji}^{\mathrm{ref}}\right)\right]^2,
    \label{eq:cross-fitted-normalization}
\end{equation}
再使用 $\widehat a_j^{(-c)}$ 和 $\widehat b_j^{(-c)}$ 归一化留出簇。该处理只消除来源间的仿射尺度差异，不改变留出轨迹的排序、曲率和局部偏差，因而归一化后的剩余误差仍能反映标度规律的跨体系可迁移性。为保持评价透明性，本文同时保留未经校准的原始尺度误差，并将其解释为“结构误差与观测尺度偏移”的合成结果。

\paragraph{可分离非线性最小二乘法}

式~\eqref{eq:classic-scaling-law}对五个参数整体而言是非线性模型，但当指数 $(\alpha,\beta)$ 给定后，$E$、$A$ 和 $B$ 构成线性参数。令
\begin{equation}
    \boldsymbol y=(L_1,\ldots,L_n)^{\mathsf T},\qquad
    \boldsymbol\theta=(E,A,B)^{\mathsf T},
\end{equation}
并构建设计矩阵
\begin{equation}
    \boldsymbol X(\alpha,\beta)=
    \begin{bmatrix}
        1      & N_1^{-\alpha} & D_1^{-\beta} \\
        1      & N_2^{-\alpha} & D_2^{-\beta} \\
        \vdots & \vdots        & \vdots       \\
        1      & N_n^{-\alpha} & D_n^{-\beta}
    \end{bmatrix}.
\end{equation}
于是，在任意候选指数对下，内层问题可写为带物理约束的线性最小二乘
\begin{equation}
    \widehat{\boldsymbol\theta}(\alpha,\beta)
    =\arg\min_{\boldsymbol\theta}
    \left\|\boldsymbol y-
    \boldsymbol X(\alpha,\beta)\boldsymbol\theta\right\|_2^2.
    \label{eq:inner-linear-ls}
\end{equation}
将内层解析解代回后，原问题被压缩为仅关于两个指数的轮廓残差平方和
\begin{equation}
    S(\alpha,\beta)
    =\left\|\boldsymbol y-
    \boldsymbol X(\alpha,\beta)
    \widehat{\boldsymbol\theta}(\alpha,\beta)\right\|_2^2.
    \label{eq:profile-sse}
\end{equation}
本文先在指数区间内设置等距节点进行粗网格搜索，再以当前最优点为中心实施局部模式搜索，并逐次将搜索步长减半，直至步长小于 $10^{-7}$。
相较于同时对五个参数进行无结构的非线性优化，该可分离非线性最小二乘方法将高维耦合问题转化为“外层低维指数搜索+内层线性求解”，既降低了初值敏感性，也便于在每个指数候选点严格检查参数正性和不可约损失边界。

\paragraph{自适应结构早停}

指数自由度越高，越容易把数据噪声读作真实的标度结构差异，因此本文按由简到繁、以外部验证收益为准的顺序逐层释放指数自由度。
第一层令 $\alpha=\beta=s$，对共享指数 $s$ 进行一维搜索。第二层以第一层最优值 $s^{\ast}$ 为锚点，分别考察“固定 $\beta=s^{\ast}$、释放 $\alpha$”和“固定 $\alpha=s^{\ast}$、释放 $\beta$”两个并列候选。只有当单方向释放产生稳定的外部收益时，第三层才进入 $(\alpha,\beta)$ 均自由的二维搜索。每个候选指数点仍由式~\eqref{eq:inner-linear-ls}估计 $E$、$A$ 和 $B$，因此该过程并未引入新的标度律项，而是在同一标准模型内部逐步增加指数自由度。

不同来源的可信度、判别难度与统计稳定性并不相同，因此本文不预先固定其权重。记 $r_j$ 为可信度先验，$d_j$ 为基准模型在该来源上的验证难度，$\sigma_j$ 为按轨迹或模型族分簇 Bootstrap 得到的分数标准差，则定义稳定性因子和原始权重
\begin{equation}
    s_j=\frac{1}{1+\sigma_j/d_j},
    \qquad
    u_j=r_j d_j^{\xi}s_j,
\end{equation}
并在给定上下限后将 $u_j$ 归一化为 $\omega_j$。较困难但稳定、且证据可靠的来源因而获得较高权重。高度相关、半合成或波动较大的来源则不会主导结构选择。权重在比较候选结构之前一次确定并冻结，以避免针对某个候选模型事后调整评价标准。

候选结构的最终选择分数定义为
\begin{equation}
    J_m=\sum_j \omega_j \operatorname{MedAPE}_{jm}
    +\lambda\max(0,k_m),
    \label{eq:early-stopping-score}
\end{equation}
其中，$\operatorname{MedAPE}$ 衡量归一化后的相对预测偏差, $k_m$ 为有效自由参数数目，第二项用于要求新增指数自由度给出足以抵消复杂度增长的外部收益。候选结构首先需要满足主拟合样本上的最低拟合门槛。随后，只有当$ J_m<J_{\mathrm{best}}-\delta $时，才将其视为实质改善并更新历史最优结构。

\subsubsection{质量加权组成响应的广义律构造}

经典标度律揭示了参数规模与训练数据量的损失衰减规律，但其同质 Token 假设无法区分训练语料的质量和来源组成。为分析这一缺口，首先考察实验的可辨识结构，在模型规模与训练 Token 数均固定的条件下，存在数百种不同的语料配比，因而经典标度律对这些实验给出同一预测基线，却无法解释其损失差异。另有 $256$ 组配比在两个模型规模下逐一对应，可比较规模改变后配比响应的形状与幅度。这说明需要在规模基线之外单独建立组成响应，而非仅用总 Token 数代表全部训练数据。与此同时，观测实验仅提供三个不同的 $(N,D)$ 规模锚点，其中较大模型的 $N$ 与 $D$ 同时变化。若连同组成效应重新估计全部规模指数，将产生明显的参数混淆。因此沿用前文估计的 $\alpha$、$\beta$，将新增参数集中用于刻画组成效应及其跨规模变化。

其次，训练配比属于单纯形，提高某一来源的份额必然压缩其他来源，故各 $p_i$ 不是相互独立的投入量。仅以平均质量 $\sum_i p_iQ_i$ 概括语料，会把质量相近但知识内容不同的来源混为一谈。只用原始份额又难以直接表达来源之间的相对替代。基于这一约束，采用质量加权份额 $p_iQ_i$ 记录各来源的有效投入，并以中心化对数比刻画相对组成。但现有质量评分对每个来源固定，$p_iQ_i$ 与 $p_i$ 在统计上不能区分独立的质量改善效应，因此这一项只表示给定质量分级下的组成暴露，不能作质量因果效应解释。

最后，逐行配对的跨规模配比为检验“响应形状相对稳定、作用幅度随规模改变”的可分离假设提供了依据。用规模幂函数调节组成响应的幅度，既与经典标度律的形式协调，也避免为每个规模重新拟合一套配比函数。以参考规模归一化该幅度，并将组成响应在参考样本上中心化，可减少其与损失截距之间的混淆。由于配比维度随来源数增长，估计时还须施加正则化以控制方差。设训练语料包含任意 $m$ 个来源，$\mathbf p=(p_1,\ldots,p_m)$ 满足 $p_i\geq0$、$\sum_i p_i=1$，$\mathbf Q=(Q_1,\ldots,Q_m)$ 为相应来源质量；本文实例取 $m=17$ 和 $\mathbf Q=\mathbf Q^{(17)}$。对于任意给定的评估目标，由此提出统一的函数结构
\begin{equation}
    \begin{aligned}
        L(N,D,\mathbf p,\mathbf Q)
        ={} & E+A N^{-\alpha}
        +B D^{-\beta}
        +\left(\frac{N}{N_{0}}\right)^{-\eta}
        \left(\frac{D}{D_{0}}\right)^{-\zeta}
        \varphi(\mathbf Q,\mathbf p),
    \end{aligned}
    \label{eq:generalized-scaling-design}
\end{equation}
其中$(N_{0},D_{0})$ 为首个观测规模锚点。$E$、$A$ 和 $B$ 决定损失基线，$\alpha$、$\beta$ 为规模指数，$\eta$、$\zeta$ 刻画组成响应随规模变化的程度。两个规模比值在参考规模均为 $1$，故 $\varphi$ 直接表示该规模下的损失修正，其符号方向与问题一的总体表现指标 $\phi(\mathbf p)$ 不同。为避免平均质量 $\sum_i p_iQ_i$ 抹去同等级、不同知识来源之间的差别，将组成响应展开为
\begin{equation}
    \begin{aligned}
        \varphi(\mathbf Q,\mathbf p)
        ={} & \sum_{i=1}^{m}w_i
        (p_iQ_i-\bar m_i) +\sum_{i=1}^{m}w_{\mathrm{clr},i}
        \bigl(\operatorname{clr}_{\varepsilon}(\mathbf p)_i
        -\bar m_{\mathrm{clr},i}\bigr).
    \end{aligned}
    \label{eq:generalized-composition-response}
\end{equation}
这里 $w_i$ 与 $w_{\mathrm{clr},i}$ 分别为质量加权份额和相对配比的有效权重。$\bar m_i$、$\bar m_{\mathrm{clr},i}$ 是对应特征在参考规模拟合样本上的均值，使 $\varphi$ 在该样本上均值为零。其中，中心化对数比定义为
\begin{equation}
    \operatorname{clr}_{\varepsilon}(\mathbf p)_i
    =\log(p_i+\varepsilon)
    -\frac{1}{m}\sum_{j=1}^{m}\log(p_j+\varepsilon).
    \label{eq:generalized-clr-definition}
\end{equation}
式~\eqref{eq:generalized-composition-response}中的 $p_iQ_i$ 记录质量加权的来源投入，中心化对数比反映单纯形上的相对结构，$\varepsilon>0$ 用于处理零占比。
拟合时对这两组特征进行标准化与正则化，并将所得系数换算为式~\eqref{eq:generalized-composition-response}中的有效权重。
不同评估目标均采用式~\eqref{eq:generalized-scaling-design}的函数结构，但 $E$、$A$、$B$、$\eta$、$\zeta$ 及组成权重分别估计。

\subsubsection{锚定分阶段广义标度律参数辨识与跨规模验证}

式~\eqref{eq:generalized-scaling-design}由经典规模基线与受规模因子调制的组成响应相加而成。若联合估计全部参数，仅有三个规模锚点不足以同时辨识经典律指数和组成响应指数。此外，响应形状与幅度可相互吸收，造成参数化不唯一。为此，本文按图~\ref{fig:generalized-law-identification} 所示采用“锚定标准律—分阶段参数辨识—因子对比”的递进结构，在保留经典律约束的同时辨识新增的组成项。

\paragraph{锚定标准律}
沿用前文由充分规模变化的实验辨识出的共享指数 $\alpha=\beta=0.293183$，只借用指数而不直接移植损失基线参数。由此将广义模型的规模基线限制在 $\{1,N^{-\alpha},D^{-\beta}\}$ 张成的空间中，避免用稀疏的配比实验重新估计指数。该锚定仅约束资源收益衰减的形状。损失下界及两个规模项的系数仍由当前评估目标的数据确定，从而不强求不同目标共享损失水平。以下 $N,D$ 分别以十亿参数和十亿 Token 计。三个观测锚点依次为 $(10^{-3},1)$、$(0.06,1)$ 和 $(1,25)$，首个锚点记为 $(N_0,D_0)$。

\paragraph{分阶段参数辨识}
在参考锚点，$N,D$ 保持不变，配比之间的损失差异因而提供组成响应的识别信息。对式~\eqref{eq:generalized-composition-response}中的两组特征逐维标准化，以岭回归估计该响应，正则强度由调参折选定。将拟合响应在参考训练配比上中心化、换算至损失单位，并规定其幅度 $\kappa_1=1$：前者使组成项与常数基线在参考样本上分离，后者固定 $\kappa\varphi$ 的尺度规范。令 $s$ 表示锚点、$r$ 表示该锚点训练折中的配比，$\varphi_{sr}=\varphi(\mathbf Q,\mathbf p_{sr})$。其余幅度是损失对同一响应形状的投影斜率。扣除组成项后得到各锚点的规模基线：
\begin{equation}
    \begin{aligned}
        \kappa_s & =\frac{\sum_r(\varphi_{sr}-\bar\varphi_s)(L_{sr}-\bar L_s)}
        {\sum_r(\varphi_{sr}-\bar\varphi_s)^2},\quad s=2,3,                    \\
        b_s      & =\bar L_s-\kappa_s\bar\varphi_s,\quad s=1,2,3.
    \end{aligned}
    \label{eq:generalized-stagewise-projection}
\end{equation}
这样，原先耦合的形状与幅度被化为参考规模的正则化回归及跨规模的一元投影。再以非负最小二乘将三个 $b_s$ 投影回锚定的经典律基底：
\begin{equation}
    (\widehat E,\widehat A,\widehat B)
    =\arg\min_{E,A,B\geq0}\sum_{s=1}^{3}
    \left(b_s-E-A N_s^{-\alpha}-B D_s^{-\beta}\right)^2.
    \label{eq:generalized-baseline-identification}
\end{equation}
非负约束保持经典基线项的物理方向。由于组成修正可为负，仍须另行检查预测损失是否低于 $E$。各评估目标采用相同的函数结构，但分别估计其基线与组成权重。

\paragraph{因子对比}
对正的响应幅度取对数，得到 $\log\kappa_s=-\eta\log(N_s/N_0)-\zeta\log(D_s/D_0)$。由于前两个锚点的 $D$ 相同，其幅度比消去了数据量因子，可先辨识 $\eta$，再从第三个锚点的总幅度变化中扣除已知的参数规模效应，条件辨识 $\zeta$：
\begin{equation}
    \eta=-\frac{\log\kappa_2}{\log(N_2/N_1)},\qquad
    \zeta=\frac{-\log\kappa_3-\eta\log(N_3/N_1)}{\log(D_3/D_1)}.
    \label{eq:generalized-amplitude-identification}
\end{equation}
上述对比利用实验设计形成的单因子变化，而不依赖同时搜索两个指数。同一配比在前两个锚点的损失还应满足 $L_2(\mathbf p)=a+\lambda L_1(\mathbf p)$，其中 $\lambda=\kappa_2/\kappa_1$、$a=b_2-\lambda b_1$。这一配对关系消去了 $\varphi$，因而可在不依赖其具体函数形式的条件下检验可分离结构。配对回归的训练折 $R^2$ 中位数为 $0.9868$，留出配比的跨规模预测相对 RMSE 中位数为 $1.16\%$。

\subsection{语料规模---质量、配比替代}

前述验证表明，资源规模项能够描述总体损失的衰减趋势，而语料质量与领域组成进一步决定相同 Token 预算下的损失差异。因而，讨论质量对规模的替代，首先需要在明确的工作点和可行配比方向上度量局部收益；不同实验尺度下的收益只有经过一致校准，才能进一步换算为等效 Token 数。

\subsubsection{各因素边际效用与弹性分析}

在损失为正、工作点位于可行域内部且局部可微时，对标量因素 $x\in\{N,D,Q\}$ 定义边际降损与损失弹性为
\begin{equation}
    g_x=-\frac{\partial L}{\partial x},\qquad
    \epsilon_x=\frac{\partial\ln L}{\partial\ln x}
    =\frac{x}{L}\frac{\partial L}{\partial x}.
    \label{eq:generalized-factor-elasticity}
\end{equation}
其中，$N,D$ 的响应由广义标度律给出；整体质量等级 $Q$ 不同于固定的来源质量 $Q_i^{(17)}$，其独立边际效应由质量实验拟合的响应模型估计，而不从广义律中的 $p_iQ_i$ 项直接推断。为使收益具有可解释的扰动尺度，规模因素报告 $L(x)-L(1.01x)$，质量因素报告 $L(Q)-L(Q+0.01)$。配比受单纯形约束，增加来源 $i$ 的份额 $t$ 时，令 $p_i(t)=p_i+t$、$p_j(t)=p_j\bigl(1-t/(1-p_i)\bigr)$（$j\ne i$），并以 $L(\mathbf p)-L(\mathbf p(0.01))$ 衡量可行方向的降损。

图~\ref{fig:factor-scale-quality-pair}(a) 给出固定参考配比下的规模弹性及配比方向收益。在已观测的 $N=10^9$、$D=2.5\times10^{10}$ 工作点，13 个评估目标的弹性中位数分别为 $\epsilon_N=-0.0345$、$\epsilon_D=-0.0868$。这表明在该点数据量的相对增益具有更高的损失敏感度，但尚不能据此比较参数与 Token 的算力效率。图中的百亿参数点仅是模型外推，不作为观测证据。图~\ref{fig:factor-scale-quality-pair}(b) 显示质量收益随 $Q$ 提高而递减：在 $Q=0.6$ 时，质量分增加 $0.01$ 的预测降损约为 $2.15\times10^{-3}$。主组 450 组与对照组 360 组存在包含关系，后者仅检验子集一致性。质量实验与广义律的损失基准尚未统一，故不能将两组导数直接相除，解释为质量提升所等效的 Token 增量。

    \label{fig:joint-mixture-effect}
\end{figure}

为将上一节的局部降损量转换为等损失的 Token 需求，以已辨识的广义标度律为主体，对数据受限项引入整体质量等级的外部标定：
\begin{equation}
    L(N,D,Q,\mathbf p)=E+AN^{-\alpha}
    +\left(\frac{Q}{Q_0}\right)^{-\gamma_Q}
    \left[ BD^{-\beta}+M(N,D)\varphi(\mathbf Q^{(17)},\mathbf p)\right].
    \label{eq:joint-quality-mixture-law}
\end{equation}
其中，$Q_0=0.6$ 是整体质量的校准点，$\mathbf Q^{(17)}$ 为问题一映射得到并在配比实验中固定的来源质量向量；$M(N,D)=(N/N_0)^{-\eta}(D/D_0)^{-\zeta}$ 为前述规模调制因子。质量指数 $\gamma_Q=0.1085$ 由单独变化质量的校准实验标定，其余参数均不重估。故 $Q=Q_0$ 时，式~\eqref{eq:joint-quality-mixture-law} 严格退化为原广义律。主口径假定质量同时作用于数据规模项与配比修正项；仅作用于 $BD^{-\beta}$ 的口径作为结构敏感性对照。主口径下，固定配比的精确局部等损失斜率为
\begin{equation}
    \left.\frac{\mathrm d\ln D}{\mathrm d\ln Q}\right|_{L,\mathbf p}
    =-\gamma_Q\frac{BD^{-\beta}+M\varphi}
    {\beta BD^{-\beta}+\zeta M\varphi},
    \label{eq:joint-iso-loss-slope}
\end{equation}
其中 $M\propto D^{-\zeta}$，$\varphi=\varphi(\mathbf Q^{(17)},\mathbf p)$。因此 $-\gamma_Q/\beta$ 仅在忽略配比项或两项具有相同数据量指数时成立，有限幅度的替代量须逐目标数值求解。

固定 $N=10^9$、替代工作点 Token 数 $D_\star=250$ 亿及参考配比 $\mathbf p_0$，将 $L(N,D_\star,Q_0,\mathbf p_0)$ 作为各评估目标的基准损失，求满足该目标损失时 $Q$ 与 $\mathbf p$ 对应的最小所需 $D$。这里 $D_\star$ 不同于广义律的规模归一化锚点 $D_0$。配比调整仅考虑观测支撑域内的方向：单一来源份额增加 $1$ 个百分点，其余来源按比例缩减。图~\ref{fig:joint-iso-loss} 展示两种示例评估领域的等损失曲线；在相同配比下提高质量使所需 Token 下降，而同一质量水平下不同配比对应不同的需求基线。图~\ref{fig:joint-mixture-effect} 用同一组真实配比进一步表明，这种配比效应的幅度具有明显的评估目标依赖性。

逐目标先对可行配比方向取节省量中位数，再对 13 个评估目标等权汇总：质量由 $0.6$ 提至 $0.7$ 时，固定配比的 Token 节省中位数为 $13.97$ 亿，叠加可行的 $1$ 个百分点配比调整后为 $14.06$ 亿；仅缩放规模项的敏感性口径分别为 $13.30$ 亿和 $13.59$ 亿。因而，小幅配比调整的总体增益有限，但图中的完整观测配比差异可显著改变所需 Token 水平，两种比较尺度不可混同。模型在 $Q_0$ 的锚定误差小于 $5\times10^{-16}$，可行求根的最大损失残差为 $2.33\times10^{-13}$。

\subsubsection{规模---质量、配比替代边界}

上述等损失换算由 $L(N,D,Q,\mathbf p)=L^\star$ 隐式定义，并非跨工作点通用的 Token 汇率。对式~\eqref{eq:joint-quality-mixture-law}，只有在 $BD^{-\beta}+M\varphi>0$ 且 $\beta BD^{-\beta}+\zeta M\varphi>0$ 时，提高质量和增加 Token 才同时具有降损效应，式~\eqref{eq:joint-iso-loss-slope} 的负斜率方可解释为局部替代。
由于组成修正 $\varphi$ 可正可负，这些条件须按评估目标、配比和工作点分别核查。识别边界同样重要：配比实验中的来源质量 $Q_i^{(17)}$ 固定，不能由 $p_iQ_i^{(17)}$ 单独辨识质量提升效应。
整体质量指数来自独立实验，其与组成项的乘性耦合是外部标定的结构假设，尚缺少同时独立改变质量与配比的实验验证。

独立改变整体质量等级的实验为局部质量响应提供了直接依据：在 $45$ 组固定 $(N,D)$ 的比较中，验证损失对 $Q$ 的线性趋势斜率均为负。包含 $450$ 条记录的拟合及其 $360$ 条记录的子集对照分别得到 $R^2=0.9568$ 和 $0.9535$；二者是包含关系，不能视为独立重复验证。在 $Q=0.6$ 的工作点，质量提高 $0.01$ 的预测降损约为 $2.15\times10^{-3}$，质量弹性约为 $-0.0482$，与负向的经验响应一致，但其边际收益随 $Q$ 提高而递减。相比之下，向更大模型和语料规模延伸的扩展结果在 $150$ 组固定 $(N,D)$ 的比较中给出全部为正的质量---损失斜率，并有 $362$ 条记录被截断于损失下界 $0.5$。这一方向冲突和截断现象表明，该扩展结果不能验证质量响应的外推，也不宜用于重标定质量指数；它并不构成“大模型中质量提升会增损”的实验证据。

因此，本文仅在观测支撑域内调整配比，并在独立质量实验标定的范围附近解释质量边际效用与弹性；质量与组成的联合替代仍须以两种耦合口径及逐目标差异进行敏感性检验。当等损失求解所需的 $D$ 偏离已观测规模，或将关系推广至更大模型时，所得节省量应视为模型情景推算，而非已实现的训练收益或因果效应。

\subsubsection{配方响应与质量桥接}

为适应配比的组成数据结构，对 $p_i$ 加入 $\delta=0.001$ 后作中心化对数比变换，并将质量加权配比与配方结构拼接为 34 维特征：

\begin{equation}\label{eq:q3_2}
    \operatorname{clr}_{\delta}(p)_i=\ln(p_i+\delta)-\frac{1}{17}\sum_{j=1}^{17}\ln(p_j+\delta),
    \qquad \delta=0.001.
\end{equation}

\begin{equation}\label{eq:q3_3}
    x=(p\odot\mathbf q,\operatorname{clr}_{\delta}(p)),\qquad
    z=\frac{x-\mu}{\sigma},\qquad
    \Phi_k=s_k(\beta_{0k}+\boldsymbol\theta_k^{\mathsf T}z-c_k).
\end{equation}

其中 $k=1,\ldots,13$ 对应评测域，$\mu,\sigma,\beta_{0k},\boldsymbol\theta_k,s_k,c_k$ 均取第二问交接文件的全精度参数。规模项与第 $k$ 个评测域的基础响应为

\begin{equation}\label{eq:q3_4}
    S_k=(n/0.001)^{-\eta_k}(d/1)^{-\zeta_k},\qquad
    L_{2,k}=E_k+A_kn^{-\alpha}+B_kd^{-\beta}+S_k\Phi_k,
\end{equation}

其中 $\alpha=\beta=0.2931826439$。为把 B7 质量标尺接入 13 域响应，先写出

\begin{equation}\label{eq:q3_5}
    F_7(n,d,Q)=0.9654077057+0.5307187920n^{-0.2825}
    +1.6157571765(dQ)^{-0.108}.
\end{equation}

主模型采用比值桥接，并用加性桥接做成本和桥接形式的敏感性检验：

\begin{equation}\label{eq:q3_6}
    \begin{aligned}
        L_k^{(r)} & =L_{2,k}\left[\frac{F_7(n,d,Q)}{F_7(n,d,Q_{\mathrm{base}})}\right]^{\kappa}, \\
        L_k^{(a)} & =L_{2,k}+\kappa\left[F_7(n,d,Q)-F_7(n,d,Q_{\mathrm{base}})\right].
    \end{aligned}
\end{equation}

两种桥接在 $Q=Q_{\mathrm{base}}$ 时都回接第二问响应；主强度为 $\kappa=1$，并取 $0.5$、$1.5$ 做正收益敏感性，$\kappa=0$ 做零收益对照。固定 $N,D,Q$ 时桥接项不改变配方排序，联合收益来自质量治理、配比、规模对同一预算的重新分配。

        幂函数 & $5\times10^9Q^4$        & FLOPs/Token，四次幂   \\
        对数  & $2\times10^9\ln(1+10Q)$ & FLOPs/Token，上界处有限 \\

令 $L_{\mathrm{ctx}}$ 为 C7 给出的外生上下文长度，质量治理只计算相对于基线的增量，则

\begin{equation}\label{eq:q3_7}
    a=6+\eta_{\mathrm{attn}}L_{\mathrm{ctx}},\qquad
    h(Q)=[g(Q)-g(Q_{\mathrm{base}})]_+,\qquad
    \eta_{\mathrm{attn}}=2\times10^{-4}.
\end{equation}

三项算力成本合并为

\begin{equation}\label{eq:q3_8}
    C_{\mathrm{used}}=C_{\mathrm{train}}+C_{\mathrm{attn}}+C_Q
    =6ND+\eta_{\mathrm{attn}}NDL_{\mathrm{ctx}}+Dh(Q)
    =D[aN+h(Q)].
\end{equation}

设 $A\in\mathbb R^{m\times17}$ 为选用的真实训练锚点矩阵，$w$ 为锚点权重，$p=A^{\mathsf T}w$。问题三的联合资源配置模型写为

\begin{equation}\label{eq:q3_9}
    \begin{aligned}
        \min_{N,D,Q,w}\quad & J(N,D,Q,w)=\frac{1}{13}\sum_{k=1}^{13}L_k(N,D,Q,A^{\mathsf T}w),                   \\
        \mathrm{s.t.}\quad
                            & D\left[(6+\eta_{\mathrm{attn}}L_{\mathrm{ctx}})N+h(Q)\right]\le C,\quad\text{(C1)} \\
                            & Q_{\mathrm{base}}\le Q\le1,\quad\text{(C2)}                                        \\
                            & 10^6\le N\le10^{11},\qquad 10^9\le D\le10^{13},\quad\text{(C3)}                    \\
                            & p=A^{\mathsf T}w,\qquad w\ge0,\qquad \mathbf1^{\mathsf T}w=1,\quad\text{(C4)}      \\
                            & L_k(N,D,Q,p)\ge10^{-6},\qquad k=1,\ldots,13.\quad\text{(C5)}
    \end{aligned}
\end{equation}

约束 (C1) 是 FLOPs 预算，(C2) 是质量可行域，(C3) 给出计算范围，(C4) 把配比限制在 A4 真实配方的凸包内，(C5) 保证响应值为正且可用于比较。13 域等权平均是明确的规划口径，不表示各领域在实际应用中同等重要；训练、注意力和质量治理三项成本是题给的 FLOPs 代理，未计入通信、存储和部署开销。主域使用 25 个锚点，随后用全部 512 行 A4 配方作方向复核；这样既保留了可计算的低维权重，又检查了缩减锚点是否遗漏真实改善方向。

上下文的影响可由成本比直接读出：

\begin{equation}\label{eq:q3_10}
    \frac{C_{\mathrm{attn}}}{C_{\mathrm{train}}}
    =\frac{\eta_{\mathrm{attn}}L_{\mathrm{ctx}}}{6},\qquad
    L_{\mathrm{ctx}}^{\mathrm{crit}}=\frac{6}{\eta_{\mathrm{attn}}}=30000.
\end{equation}

C7 中的 32768 和 131072 已超过临界长度，故本问对 2048、4096、8192、32768、131072 五档全部计算。固定上下文时，该成本比与预算无关。

\subsection{求解方法与实验设计}

\subsubsection{资源替代关系}

预算约束活跃时，固定 $N$ 和上下文后有 $D=C/[aN+h(Q)]$。质量提高带来直接 Loss 改善，同时增加每个 Token 的治理成本，因此质量方向的边际判据为

\begin{equation}\label{eq:q3_12}
    D=\frac{C}{aN+h(Q)},\qquad
    \frac{\mathrm dD}{\mathrm dQ}=-\frac{Dg'(Q)}{aN+h(Q)},\qquad
    T_Q=J_Q-\frac{J_DDg'(Q)}{aN+h(Q)}.
\end{equation}

当 $T_Q<0$ 时，提高质量仍能降低总目标，$T_Q=0$ 给出质量内点，$T_Q>0$ 时最优点停留在质量下界。$N,D$ 的驻点条件为

\begin{equation}\label{eq:q3_13}
    J_N+\lambda aD=0,\qquad J_D+\lambda(aN+h)=0.
\end{equation}

由此得到规模弹性关系和治理成本份额

\begin{equation}\label{eq:q3_14}
    \varepsilon_N=-\frac{NJ_N}{J},\qquad
    \varepsilon_D=-\frac{DJ_D}{J},\qquad
    \frac{\varepsilon_N}{\varepsilon_D}=\frac{aN}{aN+h}=1-s_Q,
\end{equation}

\begin{equation}\label{eq:q3_15}
    s_Q=\frac{C_Q}{C_{\mathrm{used}}}=\frac{h(Q)}{aN+h(Q)},\qquad
    \left.\frac{\partial s_Q}{\partial N}\right|_{Q,L_{\mathrm{ctx}}}
    =-\frac{ah(Q)}{[aN+h(Q)]^2}.
\end{equation}

式~\eqref{eq:q3_12}回答质量治理何时值得投入，式~\eqref{eq:q3_14}回答训练规模和数据规模如何分享剩余预算，式~\eqref{eq:q3_15}解释了治理份额和治理绝对成本可能呈现不同趋势。

\subsubsection{数值求解与可行域复核}

为减小 $N,D$ 跨数量级带来的数值尺度差异，采用对数坐标参数化：

\begin{equation}\label{eq:q3_16}
    \begin{aligned}
        Q_{\mathrm{hi}} & =\max\{Q\in[Q_{\mathrm{base}},1]:D_{\min}[aN_{\min}+h(Q)]\le C\},         \\
        N               & =\exp\{\ln N_{\min}+u\ln(N_{\mathrm{cap}}/N_{\min})\},                    \\
        D               & =\exp\{\ln D_{\min}+v\ln(D_{\mathrm{cap}}/D_{\min})\},\qquad u,v\in[0,1].
    \end{aligned}
\end{equation}

主求解使用 SLSQP，设置三个确定性起点；保留满足预算、质量边界、凸组合和 13 域正 Loss 条件的最优候选。对照使用 COBYQA，在 30 个共同配置上复算。完整 A4 配方复核沿

\begin{equation}\label{eq:q3_17}
    p(t)=(1-t)p+ta_r,\qquad r=1,\ldots,512,\qquad t\in\{10^{-4},10^{-3}\}
\end{equation}

逐点扫描；发现改善配方后加入候选库并重新求解。图~\ref{fig:q3_4}给出从真实锚点、方向扫描到候选复核的流程。

\textbf{结果小结：} 联合优化在平均 Loss 上取得 4.16\%--5.81\% 的改善，但改善由领域间让渡伴随而来；扩展 A4 支持域后，配置仍可进一步改善。上下文变长持续挤压 $N$ 和 $D$，成本函数的价格尺度与曲率都会改变治理轨迹。结构检验在固定配方、指数成本、最长上下文条件下发现一个质量启动事件；在联合配置的多情景检验中，没有形成稳定的结构转移。

\subsection{稳健性检验与问题三结论}

\subsubsection{有限情景的稳健配置}

对同一组候选在两种桥接和三种正收益强度下进行六情景复算。设 $X$ 为共同可行候选集，定义

\begin{equation}\label{eq:q3_21}
    J_s^{\mathrm{best}}=\min_{x\in X}J_s(x),\qquad
    R_s(x)=\frac{J_s(x)-J_s^{\mathrm{best}}}{|J_s^{\mathrm{best}}|}.
\end{equation}

以最小化最大后悔值选择稳健候选：

\begin{equation}\label{eq:q3_22}
    x_{\mathrm{rob}}\in\mathop{\arg\min}_{x\in X}\max_sR_s(x),\qquad
    v_{\mathrm{rob}}=\min_{x\in X}\max_sR_s(x).
\end{equation}

165组的最大相对后悔值为1.5465\%，零收益压力情景下为2.5946\%。这说明推荐配置对已登记桥接和收益强度具有有限幅度的稳定性；稳健性结论随候选库和情景集合一并定义。

SLSQP 与 COBYQA 在相同 25 锚点、相同 3 起点和相同配置上进行 30 对复算。60个结果均满足基本可行条件，扰动检查通过 59 个；SLSQP 为 30/30，COBYQA 为 29/30，最大均值 Loss 差为 0.000168474。求解器复算、有限后悔和零收益对照共同表明，推荐结果不是某一个局部搜索设置的单点产物。

本问计算的是第二问响应函数下的条件配置，质量桥接沿用 B7 标尺，配方支持来自 A4，实际上下文来自 C7。后续实证步骤是：先以表~\ref{tab:q3_6}选择预算和上下文下的候选，再在同一数据治理流水线上记录真实治理 FLOPs，并用 13 域评测 Loss 对 $Q$、$g(Q)$ 和桥接强度重新校准。

\textbf{问题三结论：}
\begin{enumerate}
    \item 在总成本 $C=D[(6+\eta_{\mathrm{attn}}L_{\mathrm{ctx}})N+h(Q)]$ 下，联合优化变量为 $N,D,Q,w$，配比由 $p=A^{\mathsf T}w$ 生成；这同时满足算力预算、质量上下界、尺度范围和真实配方支持约束。
    \item 在当前响应模型中，联合释放配比和治理质量使平均 Loss 改善 4.1603\%--5.8086\%，但 165 组中 162 组至少有一个评测域退步，实际部署应根据领域优先级增加逐域约束。
    \item 上下文长度通过注意力成本直接改变可用于 $N$ 和 $D$ 的预算；$L_{\mathrm{ctx}}^{\mathrm{crit}}=30000$，C7 中的 32768 和 131072 已进入注意力成本高于训练成本的区间。成本函数的价格尺度和曲率都会改变治理质量轨迹。
    \item 结构检验在固定配方、指数成本、上下文131072下发现一次质量由下界进入内点的事件；联合配置未形成通过70\%情景门槛的稳定结构转移。有限候选最大相对后悔值为1.5465\%，求解器复算的合格率为59/60。
\end{enumerate}

问题四需要解决的核心识别问题，是将前三问给出的 Loss 机制与现实模型的 Benchmark 表现统一到可比较的能力尺度。前三问依次刻画数据质量与领域配比、广义标度关系及算力约束下的最优资源配置，由此形成从预算到最优损失的机制映射 $L^*(C)$，现实样本则提供综合能力前沿 $F_t$ 和训练算力前沿 $C_t$。对两类前沿分别实施时间回归，既不能从回归系数中识别规模效应，也无法构造算力增速放缓的结构反事实。为此，本文引入 Loss--Benchmark 桥接函数 $H$ 作为观测映射，并建立统一状态方程
\begin{equation}
F_t-F_{t_0}
=\underbrace{H[L^*(C_t)]-H[L^*(C_{t_0})]}_{\text{规模机制项}}
+\underbrace{T_t}_{\text{非规模技术综合项}}
\label{eq:q4-state}
\end{equation}
其中，$T_t$ 表示前三问规模机制不能解释的锚定残差，综合反映架构、优化方法、数据工程、后训练及未观测因素，不再将其归属于某项单一技术。图~\ref{fig:q4-framework}给出从前三问机制输出到能力度量、桥接、贡献分解与预测的完整链路。历史分解与未来预测共用式~\eqref{eq:q4-state}，桥接误差和支持边界亦沿同一链路传播。后续分析依次识别 $F_t$、估计 $H$、构造 $B(C)=H[L^*(C)]$，并据此分解历史增长与推演未来前沿。

\subsection{Loss--Benchmark能力映射}

能力前沿给出了现实模型的观测尺度，但尚未回答前三问的最优损失如何进入该尺度。本节利用分层桥接样本估计 $H$，重点处理来源水平差异、单调机制约束及小样本验证误差，并将桥接结果作为规模能力函数的唯一观测接口。

\subsubsection{桥接样本的可比性分层}

前三问输出的是验证 Loss，式~\eqref{eq:q4-state}左侧则是 Benchmark 得分，两者不能直接相减。C6桥接样本要求验证 Loss 与榜单综合得分同时可用，共保留75条观测。桥接数据不进入时间前沿，其作用仅在于估计两个量尺之间的观测关系，因而发布日期差异不会被误写为时间趋势。

按实验协议的可比程度，样本分为High和Medium两层。7条High观测均来自Pythia，训练阶段与Loss口径较为一致，可用于确定映射的水平位置。68条Medium观测覆盖更多模型族，为响应曲线提供更宽的Loss范围，但其验证集、训练阶段或Loss定义存在差异。若直接混合两层样本，来源间的绝对水平差将进入能力响应，若仅使用High层，7条观测又不足以稳定辨识非线性形状。

基于上述证据结构，High层承担水平锚定，Medium层提供形状信息，来源截距与残差方差分别估计。该分工不要求不同来源具有统一的绝对Loss尺度，后续贡献分解只使用同一层内的桥接差值。由此既利用Medium层的覆盖范围，又避免其系统偏移改变规模贡献的方向。

\subsubsection{来源偏差不变的单调能力桥接}

记 $I_i^{M}$ 为 Medium 指示变量，在 Loss 分位点 $\kappa_j$ 上构造铰链基函数，建立
\begin{equation}
Y_i=\alpha+\delta_M I_i^{M}
+\sum_{j=1}^{J}\beta_j(\kappa_j-L_i)_++\varepsilon_i,
\qquad \beta_j\ge0,\quad
\operatorname{Var}(\varepsilon_i)=\sigma_{g(i)}^2.
\label{eq:q4-bridge}
\end{equation}
非负约束保证 $H'(L)\le0$，即 Loss 降低不会预测出能力下降。High/Medium 分别估计残差尺度，考虑 High 仅7条，本文以5个先验自由度向总体方差作经验收缩，避免小样本方差过小而在加权拟合中占据不合理权重。相邻铰链系数的一阶差分惩罚控制局部斜率突变，惩罚强度由分层留出交叉验证确定为10。

估计的 Medium 来源截距为$\widehat\delta_M=11.824$分。绝对截距用于吸收跨来源 Loss 水平差异，而历史分解只使用同一桥接层内的差值
$H(L_1)-H(L_0)$，故固定来源偏差严格抵消。该“来源截距可变、能力差分不变”的设定适应了当前多源小样本条件，且无需假定不同来源具有统一的绝对 Loss 基准。图~\ref{fig:q4-bridge}a仅在C6观测范围$[1.65,2.84]$内绘制桥接曲线，灰色边缘不参与拟合外推。

全样本 Loss 与能力的 Spearman 相关为$-0.549$，方向符合机制预期，但图~\ref{fig:q4-bridge}b显示绝对映射仍有明显离散。逐一删去7个Pythia观测后，末端斜率保持在$-24.61$至$-24.99$分/Loss，后续规模份额上界仅在8.431\%--8.561\%间变化，表明固定样本结论不由单个High观测主导。桥接误差仍是问题四的重要不确定性，须在后续条件模拟中完整传播。本节由此得到观测映射 $H$，下一节将其与问题三的 $L^*(C)$复合，形成规模能力函数 $B(C)$。

\subsection{规模扩张与非规模技术进步贡献分解}

在获得能力状态 $F_t$、桥接函数 $H$ 及问题三的最优损失曲线 $L^*(C)$ 后，本节考察历史能力增长中可由算力机制解释的部分。分析顺序为先构造与能力前沿同尺度的算力前沿，再形成 $B(C)=H[L^*(C)]$，最后在共同支持边界约束下给出贡献的部分识别集合。

\subsubsection{基于滚动分位的训练算力前沿构建}

为与能力前沿保持相同时间平滑尺度，训练算力前沿定义为开放权重Language域、language modeling或question answering任务中，Confident/Likely且真实报告训练FLOPs模型的三个月滚动Q90。共有617个模型满足基础元数据筛选，342个报告compute，其中326个进入可信主样本，72个仅能由$6ND$估计，203个缺失算力。主结果只使用reported compute，$6ND$仅构造敏感性曲线。

图~\ref{fig:q4-support}a显示，2023年6月至2024年6月的Theil--Sen斜率为每月$0.0812\ \log_{10}$FLOPs，2024年7月至2025年3月转为$-0.0429$。这表明2024年中跃升后进入平台/回落阶段，负的短窗口斜率不等于长期算力必然下降，故预测主情景将未来算力增速保守截为0。reported compute 与加入$6ND$后的前沿走势接近，结论不依赖估算值。

\subsubsection{机制锚定的规模能力反事实}

问题三主情景固定为context 4096、指数质量成本、ratio桥接与$\kappa=1$，在$10^{19},10^{22},10^{24}$ FLOPs三档预算下得到最优平均Loss 2.4500、1.6932、1.4803。本文仅在$\log C$--$\log L$空间对三锚点分段连接，形成继承前三问机制的$L^*(C)$，而不使用历史能力数据重新拟合“规模趋势”。由此定义规模能力函数
\begin{equation}
B(C)=H[L^*(C)],
\qquad
\Delta F_t=\Delta B(C_t)+T_t.
\label{eq:q4-mechanism}
\end{equation}
其中$B(C)$回答“在前三问配置机制与桥接关系保持不变时，仅改变算力预算应获得多少能力”。这一反事实直接连接问题三，而$T_t$只承接剩余变化，从而避免把时间回归系数直接命名为技术进步。

图~\ref{fig:q4-support}b将$L^*(C)$与C6 Loss范围叠加。Level A为较强机制支持区，Level B依赖响应形状延伸，$C>10^{24}$ FLOPs的Level C超出Q3预算。观测窗口起点和终点的算力分别为$1.729\times10^{24}$与$3.399\times10^{24}$ FLOPs，均位于Level C，对应$L^*$为1.457和1.428，又低于C6最小Loss 1.65。因此，历史分解同时越过Q3和C6边界，规模贡献在现有数据下不可点识别。

\subsubsection{支撑边界感知的贡献部分识别与稳健性}

边界之外若直接延长末端斜率，相当于将未经观测的局部响应视为确定关系，完全饱和假设则对应规模贡献的保守下界。为涵盖两种具有明确含义的边界情形，令尾部延续强度$\theta\in[0,1]$，$\theta=0$表示到达C6边界后饱和，$\theta=1$表示完整延续末段斜率。对低于观测下界$L_{\min}$的Loss定义
\begin{equation}
H_{\theta}(L)=H(L_{\min})
+\theta\{H(L)-H(L_{\min})\},\quad L<L_{\min},
\qquad \theta\in[0,1].
\label{eq:q4-partial-id}
\end{equation}
该构造不声称$\theta$具有可估计概率，而是用两个可解释边界形成部分识别集合\cite{manski2003}。将观测增长8.307分代入式~\eqref{eq:q4-state}，得到
\[
0\le \Delta F_{\mathrm{scale}}\le0.708,
\qquad
7.599\le \Delta F_{\mathrm{tech}}\le8.307,
\]
即固定样本下规模份额为0\%--8.52\%，非规模技术综合残差为91.48\%--100\%。这是一组由结构边界产生的识别集合，不是置信区间，$\theta=0$对应的“技术项100\%”只是下端边界，不能作为唯一分解结论。

\subsection{算力放缓下的能力前沿预测}

历史分解确定了规模项与非规模状态项的接口，预测阶段不再引入独立的时间序列结构，而是沿用同一状态方程推进两条路径。本节先给出算力平台与技术漂移的情景设定，再报告条件模拟、不确定性来源及滚动起点回测。

\subsubsection{算力平台--技术漂移的双状态演化}

历史残差由$T_t=F_t-F_{t_0}-[B(C_t)-B(C_{t_0})]$锚定。对其采用带漂移随机游走$T_{t+1}=T_t+b+\eta_t$，其中$b$用Theil--Sen稳健斜率估计\cite{sen1968}，得到每月1.191分，创新标准差为2.663分。该漂移描述短期非规模综合项的延续速度，不解释为某项技术的因果效应。算力主情景令未来$\log_{10}C$增速为0，无放缓反事实则延续早期每月0.0812的增速。

将两种状态代回统一方程，$h$个月后的前沿为
\begin{equation}
F_{t+h}=F_t+\bigl\{B(C_{t+h})-B(C_t)\bigr\}
+bh+\sum_{j=1}^{h}\eta_{t+j}
.
\label{eq:q4-forecast}
\end{equation}
式~\eqref{eq:q4-forecast}不是独立的时间序列模型，第一项承接现实能力，第二项仍由问题三机制和桥接决定，后两项延续式~\eqref{eq:q4-state}中的同一非规模状态。因而历史解释、反事实和预测不会因更换模型而失去可比性。

\subsubsection{历史--预测统一的能力前沿推演}

\subsubsection{预测不确定性的来源归因}

条件区间的宽度不仅取决于随机游走创新，还受到能力样本、模型族结构和跨问题机制接口的共同影响。为识别主要来源，本文采用单因素方差缩减实验，在保持其余来源随机的条件下，将第$j$类不确定性固定为主设定值，并在同一模拟抽样批次下重新估计12个月预测。定义
\begin{equation}
R_j
=
1-\frac{\operatorname{Var}(F_{12}\mid U_j=\bar U_j)}
        {\operatorname{Var}(F_{12})}.
\label{eq:q4-uncertainty-reduction}
\end{equation}
$R_j$衡量固定单一来源后总方差的相对缩减。由于各来源存在非线性交互且预测值受0--100边界截断，该指标不具可加性，也不解释为Sobol指数。

完整模拟的12个月预测方差为187.300，对应标准差13.686。图~\ref{fig:q4-uncertainty}显示，固定技术漂移与创新后方差缩减93.79\%，显著高于模型族依赖的3.71\%和能力窗口抽样的1.72\%，支持域外斜率、算力前沿、Q3成本形式及桥接样本的单因素影响均接近0。Q3成本形式和桥接样本出现$-0.00\%$与$-0.01\%$的微小负值，源于非线性交互、量表截断及有限模拟误差，不表示其产生“负不确定性”。因此，预测区间的主要宽度来自非规模技术状态的未来延续，而非对算力路径的局部扰动，该发现也与情景矩阵中技术漂移变化造成更大预测位移相互印证。

\paragraph{本问小结}
问题四得到四项主要结论。第一，开放权重chat/finetuned模型的能力前沿提高8.307分，指标信度、多口径和模型族平衡检验均支持总体上升方向，但GPQA并未同步改善。第二，来源校准单调桥接显式处理了跨来源水平偏差，绝对映射误差仍作为不确定性进入后续分析。第三，现实算力与映射Loss均超出共同支持域，规模贡献仅能部分识别，固定样本识别集合为0\%--8.52\%，不支持唯一的点分解比例。第四，算力平台情景下的12个月点预测为53.358，区间宽度主要由非规模技术状态的延续决定，且短期点预测精度未优于保持基线。综上，本文形成了\textbf{支持边界感知、来源截距不变、历史分解与情景预测统一}的能力前沿状态框架，使“能力如何度量、Loss如何映射、历史增长如何识别及算力放缓后如何演化”构成闭合证据链。
